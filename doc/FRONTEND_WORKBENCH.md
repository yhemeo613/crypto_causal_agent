# Agent 工作台 — 前端产品设计文档

> 产品定位：crypto_causal_agent 的 **操作控制台（Agent Workbench）**，从"概念展示页"升级为
> 可观察、可操控、可自动化的一体化工作台，让研究员在浏览器里完成
> **数据 → 感知 → 记忆 → 决策 → 回测 → 进化** 的完整闭环操作。

---

## 1. 产品定位与设计原则

| 维度 | 现状（概念页） | 目标（工作台） |
|------|--------------|--------------|
| 定位 | 单页展示品牌概念 | 多页操作控制台 |
| 数据 | 硬编码假状态 (`get_agent_state` 写死) | 全部来自真实 API / 数据库 |
| 交互 | 只读轮询 | 可操作：运行/停止/配置/审批 |
| 自动化 | 无 | 定时任务 + 一键实验流 + 告警 |
| 架构 | 单文件 App.vue | 路由 + 模块化组件 + Pinia + WebSocket |

**四条设计原则：**
1. **一切可观察**：Agent 每一步（感知→辩论→决策→进化）都有实时轨迹可回放
2. **一切可操控**：每个阶段都可手动触发、暂停、调整参数、审批放行
3. **默认安全**：破坏性操作（清空记忆、重置账户、停任务）必须二次确认
4. **学术可复现**：任何操作都落日志，实验结果可导出 CSV/JSON

## 3. 各模块功能设计（功能性操作）

### ① 总览 Overview
- **实时决策流**：横向时间线展示当前 Cycle 的 7 个阶段（感知→记忆→多空辩论→证伪→反事实→决策→复盘），每阶段显示状态与耗时；可点击任一步骤查看详情弹窗（LLM 原文、置信度变化）
- **系统健康面板**：数据库连接状态（TS/Neo4j/Redis/Chroma）、数据覆盖率（K线/资金费率/宏观）、API 延迟、最近错误列表
- **账户快照**：权益、浮动盈亏、回撤、今日交易次数（环形图 + 数值）
- **操作**：`开始/暂停 Agent 循环`、`触发下一轮决策`、`查看运行日志`

### ② 数据 Data
- **数据源管理**：交易所（binance/okx/bybit）、FRED、CoinGecko 的开关与代理配置
- **采集任务**：选择 symbol + 周期（1m/5m/15m/1h/4h/1d）→ `开始采集` / `强制刷新`；展示采集进度条与条数统计（复用 data_collector）
- **数据浏览器**：K 线蜡烛图 + 资金费率折线 + 宏观指标曲线，时间范围选择器，CSV 导出
- **导入管理**：parquet → TimescaleDB 导入状态（复用 data_loader.py），`重新导入` 按钮
- **操作**：`采集` / `导入` / `导出 CSV` / `删除区间数据`（二次确认）

### ③ 感知因果 Perception
- **三时序切片**：L1(1d)/L2(14d)/L3(90d) 并行卡片，各显示 trend/volatility/volume_ratio/宏观因子
- **统计因果**：Granger 检验结果表（因子对 → p-value → 方向），`运行检验` 按钮
- **因果图谱**（核心可视化）：Neo4j 图谱 force 布局渲染，节点=事件/因子（利率、情绪、价格），边=因果关系（causes_increase/triggers），边粗=置信度，点击节点查看路径
- **操作**：`运行因果抽取`（LLM 抽取）、`运行 Granger`、`编辑/删除因果三元组`、`路径探查`（输入目标事件查因果链）

### ④ 记忆 Memory
- **三层记忆总览**：瞬时窗口（列表）、向量记忆（ChromaDB 案例卡片）、因果图谱记忆（Mini 图）
- **检索实验**：输入查询场景 → 展示 Top-K 召回结果与相似度分数（`检索` 按钮）
- **操作**：`写入示例案例`、`标注正/负样本`、`清空瞬时窗口`、`清理过期向量`（自动清理已配置 24h）

### ⑤ 决策实验室 Decision Lab
- **手动决策向导**：选择 symbol + 场景快照 → `执行一轮完整决策`，实时回放 7 阶段
- **辩论回放**：多空辩论卡片（论点列表 + 证据 + LLM 原文可展开），证伪前后置信度变化动画（0.72→0.40 的下降过程）
- **反事实面板**：各情景概率/期望收益/风险的条形对比
- **参数调优**：confidence_threshold、max_leverage、position_sizing 等滑块（写回 config）
- **操作**：`执行决策`、`重跑本轮`、`采纳决策`（写入决策日志）、`放弃`、`导出推理链 JSON`

### ⑥ 回测沙箱 Sandbox
- **环境选择**：bull/bear/range/extreme 四环境切换（日期区间来自 config）
- **策略基因选择**：从进化种群挑选基因（下拉 + 基因代码预览）
- **回测运行**：`运行回测` → 绩效卡片（总收益/年化/最大回撤/夏普/胜率/交易数）
- **可视化**：净值曲线（回撤面积图）、逐笔交易散点（盈利绿/亏损红）、月度收益热力图
- **操作**：`运行` / `参数调整` / `导出报告`

### ⑦ 进化 Evolution
- **进化控制台**：种群规模/代数/变异率/交叉率/选择方法（tournament）参数表单 → `开始进化` / `暂停` / `断点续跑`（--resume N 代）
- **适应度曲线**：每代 best/avg/worst 折线 + 收敛标注
- **种群浏览器**：表格（gene_id、fitness、各环境绩效、创新分），点击行 → **基因编辑器**（AST 代码高亮预览 + `新变异` 生成）
- **操作**：`开始/暂停/续跑进化`、`手动变异个体`、`导入/导出基因`、`查看遗传谱系`（树形图）

### ⑧ 账户风控 Account
- **账户总览**：权益/余额/保证金/可用（仪表盘）
- **持仓表**：symbol/方向/开仓价/杠杆/浮盈亏/止损
- **风控规则表**：max_drawdown、max_leverage、max_daily_trades 等（读写 config）
- **交易记录**：逐笔表格 + 盈亏分布直方图
- **操作**：`平仓`、`调整止损`、`修改风控参数`、`重置账户`（二次确认）

### ⑨ 自动化 Automation
- **定时任务**：任务列表（采集 K 线、导入数据、跑决策、跑进化），Cron 式调度（如 `0 */4 * * * 采集+导入`），`新建任务` 向导
- **实验编排**：一键流水线 `采集 → 导入 → 感知 → 决策 → 回测 → 进化 → 复盘报告`（`启动全流程` / `分步执行`）
- **通知告警**：规则（回撤超限、LLM 失败、任务失败、进化收敛）→ 渠道（站内信/Webhook）
- **操作**：`新建/启停/编辑/删除任务`、`立即运行`、`查看执行历史`（每次运行的日志 + 产物链接）

### ⑩ 设置 Settings
- 配置可视化编辑（读/写 config.yaml，热生效标记）
- 密钥管理（DeepSeek/FRED/Glassnode，掩码显示）
- LLM 参数（model/temperature/max_tokens）
- 系统日志查看器（级别过滤、滚动、下载）

## 5. 自动化设计

**5.1 实时通道**
- WebSocket（`/ws`）：后端推送 `agent.step`、`db.updated`、`task.finished`、`alert` 事件；前端订阅后驱动图表热更新，替代 3s 轮询（保留轮询兜底降级）

**5.2 任务调度器（后端新增）**
- `scheduler` 模块：APScheduler 式 cron + 一次性任务，任务类型 = 采集/导入/决策/回测/进化/复盘
- 任务可组合为 **流水线（Pipeline）**：定义步骤序 + 依赖 + 失败策略（跳过/中止/重试 3 次）

**5.3 一键实验流**
- 工作台首页 `启动完整实验`：按顺序执行 采集→导入→进化(30代)→回测(四环境)→复盘，全程进度可视化，可随时暂停/断点续跑

**5.4 告警通知**
- 规则引擎：`回撤>阈值`、`决策置信度<阈值`、`任务失败`、`进化收敛` 等；渠道：站内消息中心 + Webhook（企业微信/Slack）

**5.5 自愈**
- 数据库断连自动重连并告警；LLM 调用失败自动降级（重试 → 跳过 → 告警）

## 7. 前端架构建议

- **路由**：vue-router 10 个页面，懒加载；布局组件 `AppLayout`（侧边栏 + 顶栏）
- **状态**：Pinia 拆分 `agent` / `data` / `evolution` / `account` / `tasks` / `socket` store
- **组件**：`api.js`（axios 封装 + 错误处理 + 取消）+ 通用组件（`ConfirmDialog`、`StatusBadge`、`ChartCard`、`ParamSlider`、`StepTimeline`、`JsonViewer`）
- **图表**：继续 vue-echarts 按需注册（新增 Candlestick/Graph/Heatmap/Tree/Scatter/Histogram）
- **安全**：所有写操作二次确认；任务删除/账户重置走确认弹窗；密钥掩码
- **样式**：延续暗色玻璃拟态设计语言，拆分为 CSS 变量 + 各模块 scoped 样式
